# Security Policy

## Supported Versions

Only the latest major version of this project is actively supported with security updates.

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

- **Do not** create public GitHub issues for security problems.
- Email the maintainer at: [hi@lbenicio.dev]
- Include a detailed description of the vulnerability and steps to reproduce.
- We will respond as soon as possible and coordinate a fix.

## Disclosure Policy

We aim to resolve security issues promptly. Once a fix is available, we will disclose the vulnerability and credit the reporter (unless anonymity is requested).

## Best Practices

- Always use the latest version.
- Review and follow the [LICENSE.md](./LICENSE.md) and documentation.
- Do not share sensitive credentials or secrets in public forums.

Thank you for helping keep this project and its users safe!
