# API Reference

This section documents the backend API routes built with Next.js. These endpoints are responsible for handling authentication, user profile management, and other secure server-side operations.

While these endpoints are primarily consumed by the project's frontend, they can be used by any client capable of handling cookie-based sessions.

## In this section

- **[Authentication Endpoints](./auth-endpoints.md)**: Endpoints for handling the login, logout, and OAuth2 callback flow.
- **[User Profile Endpoints](./user-endpoints.md)**: Endpoints for fetching and updating user data.
