# Cognito logout

Register your app's `/login` URL as an allowed sign-out URL in the Cognito app client. The current logout behavior and route are described in the [authentication route reference](./api/auth-endpoints.md); setup values and callback URLs are in the [Cognito guide](./guides/aws-cognito-setup.md).

This page replaces older instructions that used port 9002 and an outdated test workflow.
