# Getting started

You can run the app locally with its mock accounts and no AWS setup. Connect a Cognito user pool when you want to exercise real sign-in and account operations.

1. Follow the [installation guide](./installation.md).
2. Start with the generated local configuration. The [configuration reference](./configuration.md) explains the required values and optional integrations.
3. For real Cognito sign-in, configure the app client using the [Cognito guide](../guides/aws-cognito-setup.md).

For the full list of project commands and the source layout, see the [development guide](../DEVELOPMENT.md).
